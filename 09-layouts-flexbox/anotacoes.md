# Bloco 9 — Layouts com Flexbox

Material novo da disciplina sobre construção de layouts usando `div` e CSS Flexbox.

## Conteúdos do bloco

- Layout 1: Header, Main e Footer
- Layout 2: duas colunas
- Layout 3: Header, três colunas iguais e Footer
- Layout 4: Header, sidebar esquerda, Main, sidebar direita e Footer

## Conceitos principais

- `display: flex`
- `flex-direction`
- `gap`
- `flex`

> As anotações serão completadas conforme o estudo avançar.
