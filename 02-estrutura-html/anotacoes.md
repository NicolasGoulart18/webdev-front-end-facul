# Bloco 2 — Estrutura HTML

Anotações sobre a estrutura básica de um documento HTML.

## Estrutura básica html
    <!DOCTYPE html>
    <html>
    <head>
        <meta charset="UTF-8">
        <title>Minha página</title>
    </head>

    <body>
        <h1>Olá, mundo!</h1>
    </body>
    </html>
- DOCTYPE= Informa o navegador que estamos usando html5
