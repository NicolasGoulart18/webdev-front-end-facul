# Assets — Tech Day

Recursos utilizados pela atividade `10-atividade-layout-01`.

## Arquivos

### `rtx.webp`

Imagem utilizada nos slides do carrossel da página inicial.

O CSS usa `object-fit: cover` para preencher o banner mantendo a proporção da imagem.

### `Fahhhh.mp3`

Efeito sonoro reproduzido pelo JavaScript quando o usuário alterna entre modo claro e modo escuro.

## Organização

Manter imagens, áudios e outros arquivos de mídia dentro de `assets/` evita misturar recursos visuais com os arquivos principais de HTML, CSS e JavaScript.
