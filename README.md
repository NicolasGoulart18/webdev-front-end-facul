# WebDev Front-End — Faculdade

Repositório utilizado para organizar meus estudos da disciplina de desenvolvimento front-end da faculdade.

O conteúdo é separado em blocos para acompanhar a evolução das aulas, exercícios, revisões e projetos práticos.

## Objetivo

Centralizar exemplos, exercícios e anotações de HTML, CSS e JavaScript, mantendo o histórico de aprendizado através dos commits.

## Estrutura de estudos

- `01-fundamentos/` — fundamentos da Web, client-side e server-side.
- `02-estrutura-html/` — estrutura básica de um documento HTML.
- `03-textos/` — títulos, parágrafos e tags de texto.
- `04-links-imagens-listas/` — links, imagens e listas.
- `05-tabelas-formularios/` — tabelas e formulários.
- `06-html5-semantico/` — `div`, `span` e HTML semântico.
- `07-css/` — fundamentos e prática com CSS.
- `08-revisao/` — questões e revisão dos conteúdos.
- `09-layouts-flexbox/` — construção de layouts com `div` e Flexbox, incluindo revisão para a prova de 28/10.
- `10-atividade-layout-01/` — projeto **Tech Day**, com duas páginas e layout em Flexbox.
- `11-introducao-javascript/` — matéria de introdução ao JavaScript, com anotações e exercícios para a prova de 28/10.

## Conteúdos praticados

### HTML

- estrutura de documentos;
- tags e atributos;
- textos;
- links e imagens;
- listas;
- tabelas;
- formulários;
- `div` e `span`;
- HTML semântico.

### CSS

- seletores;
- classes e IDs;
- box model;
- `margin` e `padding`;
- bordas;
- variáveis CSS;
- `:hover`;
- transições e transformações;
- Flexbox;
- proporções com `flex`;
- `aspect-ratio`;
- `object-fit`;
- controle de overflow.

### JavaScript

No projeto Tech Day também comecei a aplicar JavaScript em funcionalidades simples:

- eventos de clique;
- manipulação de classes;
- modo claro e escuro;
- alteração de texto de botão;
- `localStorage`;
- reprodução de áudio.

O estudo formal de introdução ao JavaScript está organizado em `11-introducao-javascript/`.

### Biblioteca externa

No projeto Tech Day foi utilizado **Swiper.js** para estudar a implementação de um carrossel com autoplay, navegação e paginação.

1. revisão da teoria;
2. exemplo pequeno;
3. implementação prática;
4. exercício;
5. correção e organização;
6. commit da etapa concluída.
