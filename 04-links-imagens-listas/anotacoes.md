# Bloco 4 — Links, Imagens e Listas

> Status: concluído.

## Links
- `<a>` cria links.
- `href` define o destino.
- `target="_blank"` abre em nova aba/janela.
- `title` fornece informação adicional.

## Imagens
- `<img>` adiciona imagens.
- `src` informa o caminho da imagem.
- `alt` fornece texto alternativo e é importante para acessibilidade.
- `width` define largura.
- `height` define altura.

## Listas
- `<ul>` cria lista não ordenada.
- `<ol>` cria lista ordenada.
- `<li>` representa cada item.
- Lista aninhada é uma lista dentro de um item `<li>` de outra lista.
- Trocar `<ul>` por `<ol>` mantém a hierarquia, mas muda a apresentação para numeração.
