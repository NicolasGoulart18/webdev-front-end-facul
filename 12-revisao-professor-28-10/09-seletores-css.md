# Questão 09 — Seletores CSS

## Pergunta do professor

O que são seletores CSS e qual é a diferença entre seletores de elemento, classe e id?

## Resposta curta

Seletores CSS indicam **quais elementos HTML receberão determinadas regras de estilo**.

### Seletor de elemento

Seleciona todos os elementos daquela tag.

```css
p {
    color: blue;
}
```

### Seletor de classe

Usa ponto `.` e pode ser reutilizado em vários elementos.

```css
.destaque {
    color: red;
}
```

### Seletor de id

Usa `#` e normalmente identifica um elemento específico da página.

```css
#titulo {
    color: green;
}
```

## Para lembrar na prova

```text
p         -> elemento
.classe   -> classe
#id       -> id
```
