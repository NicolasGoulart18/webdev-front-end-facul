# Questão 13 — Flexbox

## Pergunta do professor

O que é CSS Flexbox e para que servem `display: flex`, `flex-direction`, `justify-content` e `align-items`?

## Resposta curta

Flexbox é um sistema de layout CSS usado para organizar e alinhar elementos de maneira flexível.

### `display: flex`

Transforma o elemento em um container flexível.

### `flex-direction`

Define a direção principal dos itens.

```text
row    -> lado a lado
column -> um abaixo do outro
```

### `justify-content`

Controla a distribuição dos itens no **eixo principal**.

### `align-items`

Controla o alinhamento dos itens no **eixo transversal**.

## Para lembrar na prova

```text
display: flex    -> ativa Flexbox
flex-direction   -> direção
justify-content  -> eixo principal
align-items      -> eixo transversal
```
