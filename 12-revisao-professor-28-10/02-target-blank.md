# Questão 02 — Atributo `target="_blank"`

## Pergunta do professor

Qual é a função do atributo `target` da forma que foi utilizado neste código?

## Resposta curta

`target="_blank"` faz o link abrir em uma **nova aba ou nova janela do navegador**, dependendo do comportamento do navegador.

## Exemplo

```html
<a href="https://www.exemplo.com" target="_blank">
    Abrir site
</a>
```

## Para lembrar na prova

`_blank` = abre o destino em um novo contexto de navegação, normalmente uma nova aba.
