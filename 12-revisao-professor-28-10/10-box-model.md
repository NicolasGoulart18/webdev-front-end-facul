# Questão 10 — Box Model

## Pergunta do professor

Explique a estrutura do Modelo de Caixa no CSS, detalhando suas quatro partes.

## Resposta curta

Todo elemento pode ser entendido como uma caixa formada por quatro camadas.

### 1. Content

É o conteúdo do elemento, como texto ou imagem.

### 2. Padding

É o espaço entre o conteúdo e a borda.

### 3. Border

É a borda que envolve o conteúdo e o padding.

### 4. Margin

É o espaço externo da caixa, separando o elemento de outros elementos.

## Estrutura mental

```text
margin
└── border
    └── padding
        └── content
```

## Para lembrar na prova

Do centro para fora:

`content -> padding -> border -> margin`.
