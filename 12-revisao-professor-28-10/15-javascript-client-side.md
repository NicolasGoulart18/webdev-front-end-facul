# Questão 15 — JavaScript no client-side

## Pergunta do professor

Quais são as principais responsabilidades do JavaScript no desenvolvimento de páginas web do lado do cliente?

## Resposta curta

JavaScript é responsável principalmente pelo **comportamento e pela interatividade da página no navegador**.

Entre suas responsabilidades estão:

- manipular elementos e conteúdo do DOM;
- responder a eventos como cliques e digitação;
- validar dados de formulários;
- alterar a página dinamicamente;
- consumir dados de APIs.

## Comparação rápida

```text
HTML       -> estrutura
CSS        -> aparência
JavaScript -> comportamento e interatividade
```

## Para lembrar na prova

Se algo precisa reagir a uma ação do usuário ou mudar dinamicamente no navegador, JavaScript normalmente está envolvido.
